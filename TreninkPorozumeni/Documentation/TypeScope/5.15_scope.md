# 5.15 scope (Step-0 web scope explorer, 2026-10-02)

## Type
5.15 Komplexní časové relace: slovesný vid v minulém čase (dokonavý vs nedokonavý), doc2 §5.15 (stavěla/postavila, pil/vypil, trhal/utrhl, krojila/rozkrojila, zavíral/zavřel).
- **Core contrast:** the SAME lexical verb in the past tense, in two aspects:
  - imperfective = the action is in progress (unfinished at the depicted moment);
  - perfective = the action is finished, with a visible result.
- **Picture pair:** both pictures show the same person, the same object and the same place; only the phase differs.

**Format:** 4 pictures:
- the target;
- grammatical distractor 1 (the swap partner, i.e. the other aspect phase of the same scene);
- 2 lexical distractors, wrong for BOTH sentences (a different object or a different action).

The doc's "initial phase" foil (the agent is only arriving and the object is untouched) is a third aspect phase. Blind testers could read it as the imperfective („stavěla" = "was about to / starting"). Avoid it, or use it only together with a changed noun.

## Forms inventory
- **Prefix perfective vs simplex imperfective** (purely aspectual prefix): „Holčička postavila hrad." / „Holčička stavěla hrad." Depictable: yes (core).
  - Prefixes: na- (namalovat, nakreslit, nalít, nakrájet), u- (upéct, uplést, umýt, uklidit, ustlat), po- (postavit, pověsit), s- (sníst, složit), vy- (vypít, vyčistit, vyžehlit, vybarvit), o- (oloupat, ozdobit), za- (zabalit, zavázat), roz- (rozkrojit, rozbalit), ob- (obléct, obout).
- **Suffix pairs** (imperfective -ova-/-a-/-í- vs perfective): zavírat/zavřít, otevírat/otevřít, zapínat/zapnout, oblékat/obléct, nalévat/nalít, rozbalovat/rozbalit, prostírat/prostřít, vystřihovat/vystřihnout. Depictable: yes, mostly.
- **do- perfectives** (dopsat, dopít): mean "finish the remaining part", a semantic shift. Depictable: risky; avoid.
- **Semelfactives / momentary perfectives** (skočil, kopl, chytil): a single moment, with no visible "half-done" state. Depictable: risky; exclude.
- **Iteratives -va-** (dělával, chodíval): depictable: no; exclude.
- **Perfective future vs imperfective present** („postaví/staví"): tense mixing belongs to 5.6; exclude, use the past tense only.
- **Atelic verbs** (běhal, spal, plakal, hrál si, zpíval): the perfective has no visible result. Depictable: no; exclude.
- **Results that are not visible** (přečetl, naučil se, pochopil, opravil, koupil). Depictable: no; exclude.
- **Acquisition** (HYPOTHESIS: cross-Slavic literature, no Czech norms found online):
  - Aspect morphology is produced early (about 2;0–2;6), tied to telic result verbs.
  - Adult-like comprehension of imperfective = "not finished" vs perfective = "completed" comes only around 5–6 years. Younger children often accept an imperfective-past sentence for a completed-result picture.

## Majority (marked) form
**Perfective past as target (~67% of played sentences).** Example: „Holčička postavila hrad z písku." → the castle is finished, the child stands back with the tools put down and admires it. The gram foil is the swap: the same child mid-building, half a castle, a tool in hand.

Reasons:
- **The perfective is the morphologically marked member** (prefix or suffix change). The doc names prefix decoding as the deficit („maloval" vs „namaloval").
- **Children's narrative input:** in fairy tales and picture-book narration, past-tense plot chains are carried mainly by perfective verbs („přišel, snědl, usnul"). The imperfective past mostly carries background and ongoing scenes.
  - HYPOTHESIS: no exact Czech child-input frequency count was found online; this is the standard description of narrative aspect use.
- **Scope rule table:** this matches the §9 table of the scope rule.

## Minority form(s)
**Imperfective past as target (32–34% of played sentences).** Example: „Holčička stavěla hrad z písku." → the in-progress picture.
- **Item design:** about 66 mixed-variant items. v1 is perfective (target = the result picture); v2 is imperfective (target = the in-progress picture, which is v1's gram foil). One picture set then tests both directions. No whole-minority items are needed.
- **Reason:** without these items children would learn "the finished picture is always correct". Doc items 5.15.1, 5.15.3 and 5.15.5 themselves use imperfective targets.

## Contrast kept by minority items
- **Swap:** in a mixed item, the imperfective variant's gram foil is exactly the perfective result picture, and vice versa: the same verb, object and agent, only the aspect differs.
- **Lex:** the lex pictures fail on the noun or the action, so they are false for both aspects.

## Picturability rules (hard)
- **Imperfective picture:**
  - The object is visibly HALF done: a half-painted fence with a visible paint edge, a half-full glass at the lips, a half-peeled apple with the peel hanging, a half-built tower.
  - The tool is IN USE: in the hand and touching the object.
  - The agent's posture is active and the gaze is on the work.
- **Perfective picture:**
  - The object is COMPLETE, and saliently so.
  - The tool is put down or away.
  - The agent is clearly done: standing back, smiling at or showing the result, hands free or wiping the hands.
- **Same scene:** same person, clothes, object and setting in both pictures. The difference must be bold at 512 px.
- **Eating and drinking:**
  - Imperfective: food or glass at the mouth, with a visible remainder.
  - Perfective: an empty plate or glass that is set down, cutlery laid aside.
  - Avoid "half-eaten and set down", which reads as "snědl půlku".
- **Sentence object must fit both aspects:** use an object NP that is natural with both („pil mléko / vypil mléko", „jedl jablko / snědl jablko").
- **Never use the reverse action as a lex** (zavíral vs otevíral): a half-open window is true for both.

## Diversity
- **Agents:** holčička, chlapec, maminka, tatínek, babička, dědeček, kuchař, malíř, zahradník.
- **Places:** kuchyň, zahrada, pískoviště, dvůr, koupelna, třída.
- **Morphology:** mix the prefixes na-, u-, po-, s-, vy-, o-, za-, roz-, ob- and the suffix-pair type (zavírat/zavřít).
- **Objects:** vary the object NPs and the cases (Acc mostly, with some s/do/na prepositional phrases: „nalila čaj do hrnku", „nakreslil domeček na chodník").

## Lex distractor strategy
- **What a lex shows:** the same agent and setting, but either
  - a DIFFERENT, unmistakable noun with the same verb: stavěla hrad z písku → staví věž z kostek; loupal jablko → loupe banán (only if the item is not about banánů); or
  - a DIFFERENT action on the same object: loupala jablko → krájí jablko na plátky; natíral plot → myje plot hadicí.
- **Never use as a lex:**
  - the opposite action (otevírat vs zavírat);
  - the untouched initial phase of the same verb and object;
  - a same-verb, same-object picture in any phase.
- **Must be false for both sentences:** each lex must be false for BOTH the perfective and the imperfective sentence.
- **Why-text examples:**
  - Gram, for the perfective target: „Tady hrad ještě není hotový."
  - Gram, for the imperfective target: „Tady už je hrad hotový."
  - Lex: „Tady staví věž z kostek, ne hrad z písku."

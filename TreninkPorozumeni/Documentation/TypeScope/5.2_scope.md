# 5.2 scope (Step-0 scope explorer, P18 retroactive rework, 2026-10-02)

## Type
5.2 Předložkové vazby a prostorové vztahy — doc1 §5.2 („Testují porozumění prostorovým vztahům vyjádřeným předložkami. Hodnotí se přechod od jednoduchých předložek k náročnějším a složeným strukturám."), doc3 §5.2. Retroactive rework (rule §8): text + audio only, pictures unchanged.

Grammar basis: spatial prepositions v/ve, na, pod, nad, za, před, mezi govern TWO cases — locative/instrumental for static position (kde?) and accusative for goal of motion (kam?) (na stole × na stůl, za stromem × za strom); do/z/od/k/přes/skrz/kolem express goal/source/path (kam?/odkud?/kudy?). Word order in Czech is free (aktuální členění): the place adverbial may come first („Na stole leží kniha.") without changing the meaning; only the preposition + case ending carry the relation.

## Forms inventory
- F1 Static location, figure-first order (S–V–PP), Loc/Ins: „Míč leží pod židlí." — depictable: yes (current core; after P18 134/200 = 67 % of sentences are static figure-first).
- F2 Static location, PP-first order (PP–V–S): „Pod židlí leží míč." — depictable: yes (same picture as F1; tests the preposition, not the "first noun = figure" habit).
- F3 Goal of motion, Acc after two-case preposition (na/pod/za + Acc): „Kočka skáče na stůl.", „Medvídek schoval kostku pod polštář." — depictable: yes with motion pictures (already present).
- F4 Goal/source/path prepositions do / z / ze / přes / skrz / kolem / k (Gen/Acc/Dat): „Ptáček letí z krabice.", „Pes skáče přes krabici." — depictable: yes (already present, ~18 items).
- F5 Static vs motion with the same preposition in one minimal pair (za stromem × za strom): depictable: risky/no with existing pictures (needs a new motion picture) → excluded in this text-only rework.
- F6 „u" + Gen (near) vs vedle: depictable: risky (u = vedle/near; gram pictures are usually „na/v" → fine, but „u" overlaps with lex „vedle" pictures) → excluded.
- F7 Compound/adverbial forms (uvnitř, nahoře na, dole pod, naproti, okolo): risky (naproti needs orientation; uvnitř ≈ v) → excluded.
- F8 Converse relation with ground as subject („Židle stojí nad míčem."): risky (unnatural, changes the figure) → excluded.
- Acquisition (HYPOTHESIS from general sources, not a verified Czech norm): v, na, pod early (2–3 y); za, před, vedle, nad 3–4 y; mezi 4–5 y; PP-first order understood when case/preposition decoding (not word order) is used.

## Majority (marked) form
F1: static location, figure-first order, preposition + Loc/Ins. Example: „Míč leží pod židlí."

## Minority form(s)
1. F3/F4 directional (kam?/odkud?/kudy?, Acc/Gen governed) — the already-existing motion items, both variants (≈18.5 % of sentences). Reason: case-governed goal/source contrast, depictable, already in the item set.
2. F2 PP-first word order on the v2 sentence of static items (≈14.5 %). Reason: if every sentence starts with the figure, children can solve the type by "first noun + keyword" (doc1 notes children decode keywords like „medvídek", „stůl" without the preposition); PP-first forces decoding the preposition itself and matches everyday Czech („Na stole leží…").
Total target E ≈ 33 %.

User decision 2026-10-03 (Q4): the word-order-only (PP-first) minority is accepted — "Accept and log". Logged in AGENTS/Tasks/20260930_191525_TreninkPorozumeni15Types/open_questions.md (P18 W1 5.2 scope decision).

## Contrast kept by minority items
- F2: same picture pair; „Na židli leží míč." target = old gram (ball on chair), gram = ball under chair — only the preposition differs (swap rule holds). Lex pictures stay wrong (wrong object / wrong ground / other relation) for both sentences.
- F3/F4: goal vs source / over vs into etc. — spatial relation unchanged.

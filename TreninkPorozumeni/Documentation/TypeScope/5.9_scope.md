# 5.9 scope (Step-0 web scope explorer, 2026-10-01)

## Type
5.9 Stupňování přídavných jmen a příslovcí (doc1 §5.9 „Stupňování přídavných jmen a příslovcí"; doc3 §5.9 „Komparativ a superlativ"). The type tests whether children understand degree categories: pozitiv (1st degree), komparativ (2nd degree, suffixes -ejší/-ější, -ší, -í) and superlativ (3rd degree, prefix nej- + comparative). Core contrast (doc3 5.9.1/5.9.3):
- the direction of the relation (who has MORE of the property: the subject or the standard after „než");
- polarity (menší vs větší);
- comparative vs superlative confusion.

Picture constraint: one static picture with 2–3 identical objects that differ by a bold colour (or two different nouns of similar real size).

## Forms inventory
- Comparative, regular -ejší/-ější + „než": „Modrý kbelík je plnější než zelený." — depictable: yes (fullness; dirtiness špinavější/čistší).
- Comparative -ší/-í with consonant change (vyšší, nižší, užší, širší, tenčí, tlustší, kratší, těžší, lehčí): „Žlutá stuha je užší než modrá." — depictable: yes (weight only via balance scale: risky, pilot evidence).
- Comparative, irregular (ÚJČ: dlouhý–delší, malý–menší, velký–větší, dobrý–lepší, zlý–horší): „Červený míč je větší než zelený." — depictable: yes for delší/menší/větší; no for lepší/horší (evaluative, not visible).
- Comparative of the lower pole (antonym polarity): „Zelený vlak je kratší než červený." — depictable: yes.
- Comparative as attribute/object with „než": „Kluk nese větší krabici než holčička." — depictable: yes.
- Comparative with „než" + a different noun as standard: „Strom je vyšší než dům." / „Kluk má delší šálu než tatínek." — depictable: yes (plausible pairs only).
- Absolute comparative without a standard (doc3 item 3 „Tento provázek je delší."): — depictable: no („tento" = pointing; no reference inside the picture).
- Superlative with exactly 3 objects: „Největší je modrý balón." / „Modrý balón je největší." — depictable: yes.
- Superlative of the lower pole: „Nejkratší je žlutá tužka." — depictable: yes.
- Superlative from 4+ objects / „ze všech": „Nejmenší ze všech domečků je červený." — depictable: risky (crowded 512 px picture; 3 objects suffice).
- Analytic degree „více/méně (nej-méně) + adjective": „Žlutá sklenice je méně plná než modrá." — depictable: yes (fullness), lexically harder.
- Adverb comparative, static spatial result (výš/výše, níž, dál, blíž): „Zelený ptáček letí výš než žlutý." / „Kluk hodil míč dál než holčička." — depictable: yes.
- Adverb comparative of speed/manner (rychleji, pomaleji, hlasitěji): „Pes běží rychleji než kočka." — depictable: no/risky (not visible in a static picture).
- Adverb superlative: „Nejvýš letí modrý drak." — depictable: yes (3 kites).
- Equality „stejně … jako" / „tak … jako": „Červená tužka je stejně dlouhá jako modrá." — depictable: risky (equal-picture is our lexA; needs a dedicated item design, see Contrast).
- Negated comparison „není tak … jako" / „není větší než": „Červený vlak není tak dlouhý jako zelený." — depictable: risky (overlaps 5.5 negation; the equal picture becomes borderline true).
- Pozitiv alone: „Červená tužka je dlouhá." — depictable: no (relative, no contrast inside the picture).
- Double relation (doc3 item 5 „menší než pes, ale větší než myš"): — depictable: risky (needs a pointing question; does not fit the sentence↔picture format).
- Elativ („starší paní" = fairly old, no comparison): — depictable: no; exclude.
- Acquisition age: relational pairs větší–menší, delší–kratší, lehčí–těžší are understood before about age 3; the series malý–menší–nejmenší belongs to preschool training (about 4–5); explicit standard with „než", equality and negated comparison are later (about 5–6). HYPOTHESIS level for exact ages: the Czech sources give milestones, not controlled studies.

## Majority (marked) form
Adjective comparative + „než" with an explicit standard, both poles (~40 % lower pole: menší/kratší/nižší/užší/tenčí/lehčí), objects distinguished by colour or by two nouns. This is the doc's core item and the form where children make the typical errors (direction, fixation on the named standard, polarity).

## Minority form(s)
Proposal for ≈1/3 of played sentences, preferably as v2 of mixed items:
1. Superlative with exactly 3 objects (nej-, both poles; including the adverb superlative „nejvýš"). Reason: doc3 names comparative↔superlative confusion as a typical error, and children must not learn "degree = always two objects + než". Already validated in the pilot (nejnizsisvickaruzova, 10/10).
2. Adverb comparative of a static spatial result (výš/níž/dál/blíž + „než"). Reason: covers the „a příslovcí" part of the type name; depictable.
3. Analytic „méně/více + adjective" (méně plný, nejméně naplněná — doc1 example 3). Reason: a different morphological route to the same degree; small share only.

Not proposed: lepší/horší, rychleji/pomaleji, pozitiv alone, elativ, absolute comparative, double relations (unpicturable or ambiguous). „Stejně … jako" and „není tak … jako" are optional and risky.

Mixed-item realisation of the superlative: both pictures need 3 objects. Example: v1 „Modrá svíčka je vyšší než zelená." is unsuitable with 3 objects because the third object's height interferes; the clean option is whole-minority superlative items (both variants nej-, the extreme attaches to the other colour), or a mixed item where v1 is the superlative and v2 the comparative of the two named colours only if the third object is equal to the lower one in both pictures (then „X je vyšší než Y" is true exactly in the picture where X is the extreme).

## Contrast kept by minority items
- Superlative: the gram picture is the same 3 objects with the OTHER named colour as the extreme. After the swap target↔gram, v2 names that colour. It still tests which object has the extreme degree. lexA = all three equal (wrong for both), lexB = other noun (wrong for both).
- Adverb comparative: gram = the relation reversed (the yellow bird flies higher than the green one); swap = subject and standard exchanged, exactly like the adjective comparative.
- Analytic „méně … než": gram = reversed fullness; tests polarity (méně vs the default „more") and direction.
- Equality (only if used): target = equal pair, gram = one clearly longer; v2 must be a comparative true of the gram picture („Červená tužka je delší než modrá."). Then the item contrasts equality vs inequality; lexA must change to the reversed inequality (wrong for both), lexB other noun. Needs its own design — risky.
- Negated „není tak … jako": target = subject smaller, gram = subject bigger; an equal lexA becomes borderline true, so lexA must change — risky.

# 5.10 scope (Step-0 web scope explorer, 2026-10-01)

## Type
5.10 Kvantifikátory a logické operátory (doc1 §5.10 „Kvantifikátory a logické operátory"; doc3 §5.10 „Kvantifikátory a inkluze (Logické operátory)"). The type tests whether the child understands words for quantity and set inclusion/exclusion: the universal quantifier (všechny, každý), the negative one (žádný, nikdo, nic), the partial one (některé), exclusive „jenom" and the logical operators a/nebo. Core contrast (doc3 5.10.1/5.10.3): the child must check the WHOLE set. The typical error is "tolerating an exception": the child accepts a picture where 1 element differs, or ignores the quantifier as if it were not in the sentence. doc1/doc3 use 2 grammatical distractors per item: a partial one (all but one) and a total-opposite one (none).

Format constraint (our app): 4 pictures = 1 target + 2 grammatical distractors (the FIRST one swaps with the target in v2) + 1 lexical distractor. Sets have 3–4 identical objects whose state differs by a bold, clearly visible attribute (open/closed, full/empty, on/off the table, with/without a hat).

Logic caveat: „některé" is logically true when „všechny" is true (pragmatic implicature only). Children aged 5–6 often accept „některé" for an "all" picture. So „některé" may be the TARGET only when the gram distractors are "all" and "none", and only with a clear some-but-not-all picture (2 of 4). „Některé" must never be the v2 sentence of an "all" picture.

## Forms inventory
- Universal „všechny/všichni/všechna" + state: „Všechny krabice jsou zavřené." — depictable: yes (core; 3–4 objects, all with the property).
- Universal distributive „každý/každá/každé": „Každý kluk má čepici." — depictable: yes (one-to-one assignment; the distractor is one child without).
- Negative „žádný/žádná/žádné" + negated verb: „Žádná kočka nespí." / „Na talíři není žádný bonbon." — depictable: yes (the empty-set picture needs a visible container or place).
- Negative pronoun „nikdo" (persons): „Nikdo nesedí na lavičce." — depictable: yes (empty bench, people standing nearby).
- Negative „nic": „V košíku není nic." — depictable: yes (empty basket), but the lexical distractor is weaker (it has no noun to swap) → risky.
- Partial „některé/někteří" (some-but-not-all): „Některé květiny jsou ve váze." — depictable: risky (true for "all" logically; usable only as the target against all/none, 2 of 4 shown).
- Exclusive „jenom/jen" + one subject: „Jenom holčička má zmrzlinu." — depictable: yes (2–3 persons, only one has it; gram = all have it).
- „Jen jeden / jenom jedna": „Jen jedna lampa svítí." — depictable: yes (contrast with all / none).
- „Ani jeden/ani jedna": „Ani jeden pes neštěká." — depictable: yes (= žádný; a stylistic variant, lexically heavier).
- Dual „oba/obě": „Oba kluci mají kolo." — depictable: yes with exactly 2 persons (gram = only one has it).
- „Většina" / „skoro všechny": „Většina jablek je červená." — depictable: risky (proportion judgement; overlaps all-but-one).
- „Vše/všechno" (mass): „Všechno jídlo je snědené." — depictable: risky (mass noun, the state is hard to see).
- Numerals as quantity („dva/tři"): „Na stole leží tři hrnky." — depictable: yes, but this is number/counting (partly 5.3), not quantification → exclude.
- Equality „stejně … jako" (doc1 example 3): „Kluk má stejně kostek jako holčička." — depictable: risky (requires counting; better kept rare/excluded).
- Disjunction „nebo" (doc3 item 5): „Na stole leží jablko nebo hruška." — depictable: no (a picture with both makes inclusive „nebo" true; the meaning depends on interpretation) → exclude.
- Conjunction „a" („Na stole leží jablko a hruška."): — depictable: yes, but trivial (a list of nouns, lexical rather than a logical test) → exclude.
- Acquisition (HYPOTHESIS level; Czech sources give only general milestones): all/none and „každý" in simple sets around 4–5; „některé" with its "not all" implicature and „jenom" around 5–6+ (doc3: quantifiers develop latest, about 5–6). Exact Czech norms not found online.

## Majority (marked) form
The universal quantifier „všechny/všichni/všechna" and the distributive „každý" on a set of 3–4 objects, target = the whole set has the property. Gram distractor 1 (swap) = the total-opposite set „none" (all closed vs all open), gram distractor 2 = all-but-one (exception). Lex = another noun with the same state. This is doc3's detailed item and the classic "exception tolerance" error.

Swap rule for majority items: v1 „Všechny krabice jsou zavřené." (target all closed); v2 = the picture with all open: „Všechny krabice jsou otevřené." OR (preferred, mixed) the minority „Žádná krabice není zavřená." The all-but-one picture stays wrong for both sentences. Lex (other noun, all closed) is wrong for both only if its noun differs — OK.

## Minority form(s)
Proposal ≈1/3 of played sentences, preferably as v2 of mixed items:
1. Negative „žádný/žádná/žádné … ne-" and „nikdo" (empty-set statement). Reason: doc1 ex. 4 and doc3 item 2; the clearest contrast to „všechny"; it fits as v2 of an all-item (the none picture becomes the target).
2. Exclusive „jenom/jen jeden" (doc3 item 4). Reason: the exception picture (exactly one differs) becomes a target, so it uses the same 3-picture set: v1 „Všechny lampy svítí." (all on) / v2 „Svítí jenom jedna lampa." (only one on). Gram distractor 1 = all on/only-one swap; distractor 2 = none on.
3. „Oba/obě" with exactly 2 persons — a small share. Reason: the dual form; gram = only one.
4. „Některé" — only as a target in a few whole-item designs (2 of 4 shown; distractors all and none; v2 = „Všechny …" with all picture). Optional, max ~2 items in the type; pilot first.

Not proposed: nebo, a, numerals, většina, stejně … jako, nic (weak lex), vše (mass).

## Contrast kept by minority items
- Žádný as v2: target(v1)=all-with-property becomes gram(v2); the none picture is the v2 target. The partial picture (one exception) remains wrong for both („všechny" false, „žádná" false) → still tests whole-set checking. The verb must be negated (Czech double negation „žádná … není") — keep sentences short.
- Jenom jeden as v2: the swap partner is the all-picture; the none-picture is wrong for both (jen jedna ≠ žádná). Tests exclusion vs universality.
- Oba: target both, gram = only one (swap: „Jen jeden kluk má kolo."), 2nd gram = none.
- Některé (target): gram1 = all (swap partner v2 „Všechny květiny jsou ve váze."), gram2 = none. Note: in v2 the „některé" picture is NOT logically true for „všechny" → clean. The reverse direction (v1 všechny, v2 některé) is FORBIDDEN because the all-picture also satisfies „některé".
- Lex: always another noun with the same state pattern; check against both sentences.
- Picture rule: count objects identical in all 3 grammatical pictures (3 or 4), only the state changes; the state must be visible at 512 px (lit/unlit, open/closed, full/empty, hat on/off).

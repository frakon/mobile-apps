# 5.4 Scope (web scope explorer output)

## Type
5.4 „Slovesný rod" (aktivum vs pasivum). Existing items: two actors, one acts on the other. The target and gram pictures are a role-swapped pair. The lex pictures replace one actor. Before P18, all 200 variant sentences used the periphrastic passive. Picture constraint (P18, text+audio only): the minority form must be realised by text changes only, against the existing pictures.

## Forms inventory
- Periphrastic passive with an instrumental agent: „Opice je utírána zajícem." — depictable: yes (current majority)
- Active voice, SVO, unambiguous accusative object: „Zajíc utírá opici." — depictable: yes (it describes the same scene as the passive)
- Active voice, OVS order: „Opici utírá zajíc." — depictable: yes, but risky. This is the 5.1 contrast (word order vs case), not voice, and it overlaps type 5.1.
- Active voice where nominative = accusative (neuters such as štěně, kotě, prase, tele; „myš"): depictable: no. Who acts is decided by word order alone, so the sentence is ambiguous.
- Reflexive passive („Opice se utírá."): depictable: no. It cannot express an agent. With an animate subject it reads as reflexive („wipes itself").
- Passive without an agent („Opice je utírána."): depictable: no. It does not decide between the two role-swapped pictures.
- Resultative passive („Opice je utřená."): depictable: risky (it shows a finished state, not the ongoing action in the pictures).

## Majority (marked) form
Periphrastic passive (být + passive participle + bare instrumental agent). The type's diagnostic target: the child must not take the first noun as the agent. Passive comprehension in Czech develops late, roughly 5–7 years (logopedic diagnostics, TROG-type tasks).

## Minority form(s)
Active voice (činný rod), SVO, in the present tense with the same verb and the same adjunct („v kolečku", „na zádech", „do ucha", „na saních"):
- Used only where the patient's accusative is formally distinct from its nominative (e.g. not štěně, kotě, prase, tele, myš as the object).
- Mostly in v2 (v1 passive / v2 active). About a quarter of the mixed items are the other way round (v1 active / v2 passive), so that „active = v2" does not become a new positional shortcut.
- Reason: the user rule names this case explicitly. The active is the frequent, unmarked voice, so the child has to process both voices instead of learning „reverse the roles".
- OVS active was rejected: it belongs to 5.1 and adds a second contrast.
- Reflexive passive and agentless passive were rejected: they cannot be depicted with role pairs.

## Contrast kept by minority items
The gram distractor is still the role-reversed picture. Example: „Opice utírá zajíce." is true for the monkey wiping the hare and false for the hare wiping the monkey. Both lex pictures remain false (wrong actor in agent or patient position). The child must still decode who acts on whom from voice and case.

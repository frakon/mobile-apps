# 5.5 scope (Negace) — TestTypeScopeRule §3

## Type
5.5 Negace (zápor) — understanding that a negated sentence describes the scene where the action/state/object is absent. Doc reference: test-type doc section 5.5; app items `src/items/field55.ts`.

## Forms inventory
- Verbal sentence negation with ne- prefix: „Holčička netelefonuje." — depictable: yes (the figure visibly does another action)
- Negated possession/state: „Pán nemá deštník.", „Lampa nesvítí." — depictable: yes
- Negative pronoun + negated verb (multiple negation): „U stolu nikdo nesedí.", „Na talíři nic není." — depictable: yes (empty place)
- Negative determiner žádný: „Žádný pes neběží.", „Ve váze nejsou žádné květiny." — depictable: yes (group/container)
- Coordinated negation ani … ani: „Kluk nemá čepici ani šálu." — depictable: yes
- Affirmative counterpart (no negation): „Holčička telefonuje." — depictable: yes
- Partial negation („Někdo nepřišel"), member negation („Ne mně, ale jemu…"), word negation (nevelký, nepřítel) — depictable: risky/no (needs contrastive context or is lexical) — not used
- Negation with nikdy (temporal) — depictable: no (needs time course) — not used

## Majority (marked) form
Negated sentences (all forms above: ne-verb, nikdo/nic/žádný, ani…ani). The type tests that the child does not ignore the negation.

## Minority form(s)
Affirmative sentences (same verbs, no negation). Reason: if both variants were always opposite polarities in a fixed 50/50 pattern, the rule ratio is not met; the user rule wants roughly 1/3 of played sentences in the unmarked (more frequent) form so the child does not learn „the negated reading is always correct", while ~2/3 keep training negation.
Before P18 every item had v1 negated + v2 affirmative (E = 50 %). P18 (2026-10-02): items get a negated v2 that targets the affirmative-scene picture by negating the target picture's alternative action („Holčička nekreslí obrázek." — she telephones). Final state after P18 R1 (2026-10-03): **25 items have a negated v2, 75 keep v1 negated + v2 affirmative, so E = 75/200 = 37.5 %** (groups of 10: 3.0, 3.5, 3.5, 4.0, 4.5, 4.0, 3.5, 3.5, 4.5, 3.5; max pure-majority run 3; order unchanged, seed 550055). Above the 32–34 % target by user decision Q5 „Accept larger minority, vary verbs" (Q14: 33–50 % only when diversity demands it): the negated v2 must name what the figure does in the v1 target picture, and most remaining targets show only a posture (sedí/leží/spí/stojí) or eating/drinking. Diversity caps: max 3 negated v2 per verb (sedí 3, leží 3, spí 3, jí 3, mává 3, pije 2, stojí 2, kreslí/telefonuje/zvedá/plave/čte/drží 1), nejí/nepije 5 items. History: W3 converted 34, the diversity repair made it 32 (E 34 %), P18 R1 reverted 8 posture items to their original affirmative v2 and converted „Kluk jí zmrzlinu." → „Kluk nedrží balónek.".

## Contrast kept by minority items

New negated v2 („Holčička nekreslí obrázek.") — the distractor is the scene where she does draw, so the child must again process which verb is negated.

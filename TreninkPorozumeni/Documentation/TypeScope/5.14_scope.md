# 5.14 scope (Step-0 web scope explorer, 2026-10-01)

## Type
5.14 Instrumentální konstrukce (doc2 §5.14: nástroj děje vs. společnost v 7. pádě). Core contrast: bare instrumental = TOOL / MEANS („píše tužkou") vs „s/se + Ins" = COMPANION (komitativ/sociativ, „píše s tátou"). Doc distractors with animated objects (dancing table, talking toothbrush, „tatínek as a knife") and unnatural swaps („čistí zuby s kartáčkem", „krájí chleba s tatínkem" read as a tool) are REJECTED (user answer): both sentences natural, both pictures plausible, no animated objects.

Format: 4 pictures = target + gram distractor (swap partner) + 2 lex distractors (wrong for BOTH sentences).

## Forms inventory
- Instrument, bare Ins (tool held in hand): „Holka kreslí křídou." / „Táta krájí chleba nožem." — depictable: yes (core majority).
- Body part as instrument: „Kluk kope do míče levou nohou", „píše levou rukou" — depictable: risky (left/right) → use only bold contrasts (ruka vs noha: „Kluk hraje míč hlavou / nohou").
- Means of transport, bare Ins: „Babička jede vlakem / autobusem / na kole" — depictable: yes (tool-like means; good for diversity).
- Material/substance: „Máma maluje zeď barvou", „zalévá vodou" — depictable: risky (substance hard to tell) → few items, only visibly different (mléko vs voda not; barva vs křída ok).
- Comitative „s/se + Ins" with a PERSON or animal companion: „Holka maluje s babičkou." „Kluk jde s pejskem." — depictable: yes (minority).
- „s + Ins" attribute/accompaniment of a carried object: „Táta jde s deštníkem" (= has umbrella) — depictable: yes but it is NOT tool vs companion; meaning near „má deštník" → risky; use at most a few, only where the bare-Ins pair is natural („Táta jde s kufrem" vs no natural pair) → excluded.
- Motion verbs hýbat/mávat/točit/házet/kývat + Ins (object moved): „Kluk mává vlajkou", „Holka točí klíčem" — depictable: yes, but the alternative with accusative („točí klíč") is near-synonymous → NOT a contrast; „mává vlajkou" vs „mává s tátou" (waves together with dad) is natural → usable as majority-form items for verb diversity.
- Prepositional Ins of place (před/za/nad/pod/mezi + Ins): „Kočka je pod stolem" — depictable: yes but is type 5.2 → excluded.
- Passive agent („Dopis byl napsán tátou") — type 5.4, also bookish → excluded.
- Predicative Ins („Táta je lékařem", „stal se kuchařem") — not depictable as contrast → excluded.
- Ins of time/way („jde lesem", „ráno") — path „jde lesem / jde s lesníkem" risky → excluded.
- „s + Ins" ambiguity „krájí chleba se sýrem" (bread with cheese) — garden-path, FORBIDDEN.
- Acquisition (HYPOTHESIS, no Czech norms found online): bare tool Ins and s+Ins companion both used by ~3–4 y; children over-use „s" for tools („píše s tužkou") in colloquial speech → this is exactly the error the type targets.

## Majority (marked) form
Bare instrumental TOOL / MEANS. Item pattern (mixed): agent X does activity A.
- v1 (majority) „Holka maluje štětcem." → T: girl ALONE painting with a brush.
- v2 (minority) „Holka maluje s babičkou." → G: girl and grandma painting together, both with CRAYONS (no brush visible!).
- Lex 1: girl alone painting with crayons (no brush, no grandma) — false for both.
- Lex 2: girl painting with a brush together with DĚDEČEK? NO: brush makes v1 true. Use: girl with dědeček, both with crayons? → false for v1 (no brush) and v2 (not babička) — OK. Rule: every lex has neither the named tool nor the named companion.
The swap: T and G differ in BOTH tool and company, so each sentence is true in exactly one picture.
Majority-only (both variants Ins tool) items allowed for diversity: „which of two tools": v1 „Táta krájí chleba nožem." / v2 „… pilkou"? Prefer real everyday tool pairs: tužka/pastelka? (too similar) — use bold pairs: lžíce/vidlička, štětec/křída, koště/hrábě, kladivo/klíč, vlakem/autobusem, mává vlajkou/šátkem.

## Minority form(s)
Comitative „s/se + Ins" with a person or animal companion (babička, táta, kamarád, pes, sestra…), ~66 mixed items × v2 = 33% expected. Reason: scope rule Q&A 5 (same contrast) + table §9 („comitative s + Ins"); it is the natural spoken counterpart and prevents the shortcut "the answer is always the tool".
Optional: a few whole-minority items („Kluk jde s tátou" / „… s mámou") ONLY if the ratio needs it — they test companion identity, not the core contrast → avoid.

## Contrast kept by minority items
The minority target (companion picture) is the swap partner of the tool picture: hearing „s babičkou" the child must reject the lone-with-tool picture, hearing „štětcem" reject the together picture. Lex pictures violate both (wrong tool AND wrong/no companion).

## Pattern examples (words within ~2000 most frequent; vary verbs/tools/companions)
- Kluk píše perem. / Kluk píše s tátou.
- Máma krájí chleba nožem. / Máma krájí chleba s babičkou. (G: babička holds the bread, máma cuts with a different knife? NO—knife implied; prefer activities where tool is optional/swappable: krájí → avoid)
- Holka kreslí křídou. / Holka kreslí s kamarádkou. (G: both with pastelky on paper)
- Táta jede do města autem. / Táta jede do města s mámou. (G: both on bikes/bus)
- Kluk mává vlajkou. / Kluk mává s dědou. (G: both waving empty hands)
- Babička jí polévku lžící. / … s vnukem? → „jí lžící" vs „jí s klukem": G must show no spoon (eating from a mug) — check plausibility.
- Táta zametá koštětem. / Táta zametá s klukem. (G: both with hrábě on leaves) 
- Kluk hraje míč hlavou?/ … avoid.
- Holka hází míčem. / Holka hází s pejskem? → risky (with a dog throwing) — prefer „hází míč s tátou"? (acc changes) — avoid.
Rule: the tool in v1 must be absent in G and in both lex pictures; the companion of v2 absent in T and lex; activity verb identical in both sentences.

## Pitfalls
- Implied tool: if the activity needs the tool (krájet → nůž, zametat → koště), G must show a plausible alternative tool, else „s X" picture implies v1's tool → prefer swappable tools.
- No animated objects; no „s + tool" colloquial usage („píše s tužkou") as target — it is colloquially accepted and would be ambiguous.
- No „s + food" attributes (chleba se sýrem), no prepositions před/za/nad/pod/mezi (5.2), no passive (5.4).
- Person identity bold (babička grey hair, táta beard, kamarádka other hair colour); companion must visibly do the activity together, not just stand by.
- Diversity: ≥20 different verbs, ≥30 tools, ≥8 companions; include transport (vlakem/autobusem/na kole avoided—„na kole" not Ins).

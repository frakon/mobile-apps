# 5.11 scope (Step-0 web scope explorer, 2026-10-01)

## Type
5.11 Pronominalizace a anaforické vztahy (osobní, přivlastňovací a ukazovací zájmena) — doc2 §5.11. The type tests whether the child links a pronoun to the right referent ("whose is it / who is meant") when the name is replaced by a pronoun. The doc's core examples are the possessive contrast „její/jeho" vs reflexive „svůj/svou" (5.11.1 „Maminka dává holčičce její panenku."; 5.11.2 „svého psa … jeho kočku"). doc2 items are long (two clauses, mikropříběh) and rely on "obviously owned" objects (doll looking like a mini-mum), which is not depictable unambiguously → constrain heavily.

Format constraint (our app): 4 pictures = target + 1 gram distractor (swapped with target in v2) + 2 lex slots. Whole sentence max ~8 words, mostly the 2000 most frequent Czech words.

Grammar basis (ÚJČ příručka): „svůj" = owned by the SUBJECT of the clause; „jeho/její" = owned by someone else (not the subject). „Pavel vychovává své děti" vs „Pavel vychovává jeho děti" (someone else's). „jeho" = male/neuter owner, „její" = female owner, „jejich" = plural owner.

## Forms inventory
- Possessive „jeho/její" referring to the non-subject person named in the same sentence: „Kluk podává holčičce její míč." — depictable: yes (with the ownership colour convention below; this is the core).
- Reflexive possessive „svůj/svou/své/svého": „Kluk podává holčičce svůj míč." — depictable: yes (same picture set; the subject's colour).
- „jeho" vs „její" with no other cue (gender of owner only), e.g. „Maminka nese jeho tašku." — depictable: risky (antecedent not in sentence → adults remark "whose?"). Use only when both a male and a female possible owner are named in the same sentence.
- Plural „jejich" vs singular „její/jeho": „Tatínek nese jejich míč." — depictable: risky (needs 2 co-owners sharing one colour; ownership by a group is weak at 512 px).
- Personal pronoun gender as object „ho/ji/je": „Holčička má psa a kočku. Hladí ji." — depictable: yes in principle (ho = pes, ji = kočka, by grammatical gender), but needs two sentences; risky for length, keep tiny share or none.
- Personal pronoun subject „on/ona": „Kluk a holčička jdou ven. Ona nese míč." — depictable: yes but 2 sentences; risky (stylistically marked, Czech normally drops subject pronouns).
- Reflexive „se/si" vs „ho/ji" (self vs other): „Kluk se myje." vs „Kluk ho myje." (ho = pes/bratr) — depictable: yes for se vs ho when the other referent is named: „Táta myje psa, a pak se utírá." risky; simpler „Holčička se češe." vs „Holčička češe panenku." is a lexical noun, not a pronoun contrast. Use only „Kluk se myje / myje ho" with a named antecedent → risky, pilot only.
- „sebe/sobě" vs „jemu/jí": „Holčička kreslí sebe." vs „Holčička kreslí ji." (a picture on easel) — depictable: risky (portrait similarity).
- Demonstratives „ten/ta/to" (anaphoric, doc2 „s tou její hračkou"): depictable: no (no visible contrast) → exclude.
- Clause-crossing anaphora („Kočka chytila myš, když žrala její sýr.", doc2 5.11.5) — depictable: no (animal ownership of cheese, temporal clause) → exclude.
- Acquisition (HYPOTHESIS; no Czech norm source found online): personal pronouns on/ona and „můj" early (3–4 y); correct reflexive „svůj" vs „jeho/její" binding is late (5–7 y+), which is why it is the diagnostic contrast.

## Majority (marked) form
Possessive „jeho/její/jejich-free" non-subject reference: S (person A) + verb + person B (Dat/Acc/prep) + „jeho/její" + object, where the pronoun gender points to B (the only person of that gender in the sentence). Example: „Kluk podává holčičce její míč." Target = the ball in the girl's colour; gram = identical scene but the ball in the boy's colour.

## Minority form(s)
1. Reflexive „svůj/svou/své/svého" (target ≈ 1/3, mostly v2 of mixed items on the SAME picture set): v2 „Kluk podává holčičce svůj míč." → the previous gram picture (ball in boy's colour) becomes target. Reason: this is exactly the doc's svůj/její contrast; it prevents the shortcut "the owner is always the other person".
2. Optional small share (≤ 5 items, pilot first): „ho/ji" object pronoun by grammatical gender of two animals/objects named in a preceding short clause („Holčička má psa a kočku. Krmí ji."). Only if pilot is clean; otherwise drop.
Recommendation: ~66 mixed items (v1 jeho/její, v2 svůj) → E ≈ 33 %. Also allowed reversed (v1 svůj, v2 jeho/její) in some items for variety; count svůj as minority.

## Contrast kept by minority items
- Same 2 persons, same action, same object type in target and gram; only the owner colour of the object differs → svůj (subject's) vs jeho/její (the other person's). Swap rule holds exactly.
- Lex A = same scene but a different object (wrong noun) in owner-neutral colour, or wrong action; lex B = roles reversed by action AND wrong noun → wrong for BOTH sentences. Never use a lex picture with the same noun in either owner colour.

## Picture conventions (proposal)
- Exactly 2 people of clearly different gender/age class: kluk vs holčička, tatínek vs maminka, dědeček vs babička. Never two same-gender people (then „jeho/její" can't disambiguate and „svůj" vs „jeho" needs look-alikes).
- Ownership: each person wears ONE bold distinct colour (e.g. boy all-blue T-shirt + cap, girl all-red dress); their objects have the same colour AND same pattern (e.g. red with white dots). Optionally a second same-colour object of the owner visible near them (red backpack beside the girl) to strengthen ownership. Colours: blue vs red/yellow vs green; never similar hues.
- The object in action is held/given/carried clearly between them; object types big and simple (míč, čepice, kolo, taška, hrnek, kniha, deštník, auto-hračka, šála, bota).
- No dolls/portraits/mini-copies of people (doc2 5.11.1 convention rejected).
- why-texts must state the colour convention ("červený míč je holčičky – má stejnou barvu jako její šaty").
- HIGH RISK note: ownership by colour is a convention; blind evaluators may remark "ownership not shown". Pilot must verify; if needed, add a visual hint the sentence does not rely on (owner's identical-colour backpack/cap).

## Patterns to AVOID
- Pronoun with no antecedent in the sentence („Maminka nese jeho tašku.").
- Two same-gender persons (jeho ambiguous between both; „svého" vs „jeho" needs look-alikes).
- Same-gender subject and recipient with „jeho/její" (e.g. „Tatínek dává klukovi jeho čepici": colloquially „jeho" is sometimes used for the subject's own, so adults hesitate) → use only cross-gender pairs where the pronoun gender also points to the non-subject.
- Note: „Kluk podává holčičce jeho míč" is formally possible (jeho = third male) — never use jeho with a male subject; use „její" for female object person, „jeho" only with female subject and male object person.
- Animals as owners, cheese/food ownership, clause-crossing temporal anaphora (doc2 5.11.4/5.11.5), ten/ta demonstratives, sebe/portraits, plural jejich, ownership via doll appearance.
- Colloquial use of „jeho/její" for subject's own (ÚJČ: emphasis/advertising) — never make target hinge on it.

## Pilot sketches (5)
1. v1 „Kluk podává holčičce její míč." (red ball, girl red) / v2 „Kluk podává holčičce svůj míč." (blue ball, boy blue). Lex A: boy gives girl a book (neutral). Lex B: girl gives boy a cap.
2. v1 „Holčička nese klukovi jeho tašku." (blue bag) / v2 „Holčička nese klukovi svou tašku." (yellow bag, girl yellow). Lex A: girl carries umbrella to boy. Lex B: boy pulls girl's sled.
3. v1 „Maminka půjčuje tatínkovi svůj deštník." (green, mum green) / v2 „Maminka půjčuje tatínkovi jeho deštník." (blue). (reversed order item.) Lex A: mum gives dad a cup. Lex B: dad opens umbrella alone in rain.
4. v1 „Babička myje dědečkovi jeho hrnek." (brown) / v2 „Babička myje dědečkovi svůj hrnek." (purple, babička purple). Lex A: babička washes a plate. Lex B: dědeček drinks from cup.
5. v1 „Tatínek opravuje holčičce její kolo." (red bike) / v2 „Tatínek opravuje holčičce své kolo." (blue big bike). Lex A: tatínek washes a car. Lex B: girl rides scooter.
Grammar check: female subject + male recipient → „jeho"; male subject + female recipient → „její"; svůj always = subject.

# 5.13 scope (Step-0 web scope explorer, 2026-10-01)

## Type
5.13 Dativní vazby a rozlišení příjemce děje (komu/čemu vs. kdo/co) — doc2 §5.13. Tests whether the child understands WHO is the recipient (dative, 3. pád) vs who is the agent (nominative) and what is the transferred object (accusative). Core doc example: „Chlapeček dává dědečkovi dárek." ↔ gram distractor „Dědeček dává chlapečkovi dárek." (case inversion). doc2 also lists directional „Kočka utíká ke psovi." (k + Dat), „Dívka ukazuje kamarádce knížku.", „Pán hází psovi míček.", „Holčička češe koníkovi hřívu." (possessive/benefactive dative).

Grammar basis: dative = 3rd case (komu, čemu); typically the addressee/recipient with ditransitive verbs (dát / půjčit / poslat / říci něco někomu); further functions: dativus commodi/incommodi (prospěch: „uvařit někomu"), dativus possessivus („češe koníkovi hřívu" = his mane), ethic dative (not depictable), prepositions k, proti, naproti, díky, kvůli + Dat.

Format constraint (our app): 4 pictures = target + 1 gram distractor (swapped with target in v2) + 2 lex slots; sentence ≤ ~8 words; vocabulary mostly within the 2000 most frequent Czech words.

## Forms inventory
- F1 Recipient dative, canonical order S–V–Dat–Acc: „Chlapeček dává dědečkovi dárek." — depictable: yes (core).
- F2 Recipient dative, order S–V–Acc–Dat: „Maminka podává hrnek tatínkovi." — depictable: yes.
- F3 Dative-first (topicalised) order Dat–V–S–Acc: „Dědečkovi dává chlapeček dárek." — depictable: yes; tests case marking instead of word order (strongest test of the contrast; children relying on "first noun = agent" fail).
- F4 Accusative-first O–V–S–Dat: „Dárek dává chlapeček dědečkovi." — depictable: yes but stylistically marked; tiny share only.
- F5 Pronoun dative mu/jí/jim with named antecedent: „Tatínek má hlad. Maminka mu nese polévku." — depictable: risky (2 clauses, length); „Holčička jí podává míč" without antecedent = no.
- F6 Plural dative (-ům, -ám, dětem, lidem): „Paní kuchařka dává dětem polévku." / „Kluk hází holubům chleba." — depictable: yes (group vs one person; plural recipient vs plural agent swap is clean: „Děti dávají paní kuchařce…" risky semantically → prefer animals: „Holčička dává kachnám chleba.").
- F7 Dative person vs accusative person (both persons, one moved/shown): „Maminka ukazuje dceru babičce." vs „Maminka ukazuje dceři babičku." — depictable: risky (showing a person = pointing/presenting; needs a photo-free clear gesture). Allowed only with „podává/nese/vede" style physical transfer: „Tatínek nese miminko babičce." vs „Tatínek nese babičce… " — keep ≤ few items, pilot.
- F8 Benefactive dative (pro někoho): „Babička peče vnukovi dort." / „Tatínek opravuje holčičce kolo." — depictable: yes if the beneficiary is present and watching/receiving; swap = roles reversed.
- F9 Possessive dative (body part / thing of the recipient): „Holčička češe koníkovi hřívu.", „Maminka myje klukovi ruce.", „Tatínek zavazuje holčičce botu." — depictable: yes (very clear: action on the other person's body).
- F10 k + Dat (direction toward): „Kočka utíká ke psovi." vs „Pes utíká ke kočce." — depictable: yes (motion lines, static goal).
- F11 Other prepositions + Dat (proti, naproti, kvůli, díky): „Pes běží proti autu." — depictable: risky/no (kvůli, díky abstract) → exclude except naproti (risky).
- F12 Role reversal WITHOUT dative (transitive, Nom–Acc only): „Dědeček objímá chlapečka." — not dative; belongs to 5.1 → exclude as minority (would leave the type's contrast).
- F13 „pro + Acc" paraphrase of recipient: „Kluk nese dárek pro dědečka." — depictable: yes, but semantically "intended for", not physically received → risky; tiny share.
- F14 Ethic dative („To ti byl ale kluk"), dativus with modal/feeling verbs („Je mi zima", „Chutná mu") — depictable: no / risky → exclude.
- Acquisition (HYPOTHESIS; no Czech norm source found online): recipient dative with dát appears ~2.5–3 y in production; comprehension against word order (dative-first) is late (5–7 y), the reason dative-first is diagnostic.

## Majority (marked) form (~66–68 %)
F1/F2 recipient dative with a transfer verb, in normal S–V order (agent first), two clearly distinct persons/animals; gram distractor = same scene with agent and recipient swapped. Example: v1 „Chlapeček dává dědečkovi dárek."

## Minority form(s) (~32–34 %) and reason
1. F3 dative-first order „Dědečkovi dává chlapeček dárek." (main minority, ~18–20 %). Reason: if every sentence starts with the agent, children solve the type by word order ("first person gives") and never decode the -ovi/-ce/-i ending. Dative-first forces case reading — exactly the scope rule's "don't learn a shortcut" goal; same picture set (target and gram swap).
2. F10 k + Dat direction („Kočka utíká ke psovi." ↔ „Pes utíká ke kočce.") (~6–8 %). Doc-listed (5.13.2); same "who is the goal" contrast.
3. F9 possessive/benefactive dative („Maminka češe holčičce vlasy." ↔ „Holčička češe mamince vlasy.") (~6–8 %). Doc-listed (5.13.5); recipient = affected person.
Optional pilots (≤ 3 items total): F6 plural recipient, F7 Dat-person vs Acc-person, F4.
Recommendation: ~66 mixed items (v1 majority F1/F2, v2 minority F3/F10/F9) → E ≈ 33 %. The hypothesis table's "role swap without dative" (F12) is rejected: it drops the dative contrast (rule §6).

## Contrast kept by minority items
- F3: same lexemes, same picture pair; „Dědečkovi dává chlapeček dárek" target = boy gives; gram = grandpa gives. Typical v1/v2 pairing: v1 „Chlapeček dává dědečkovi dárek." (target A gives) / v2 „Chlapečkovi dává dědeček dárek." (target B gives, dative-first) — the swap rule holds and the child cannot use word order.
- F10: goal of motion swapped (gram = the other animal runs).
- F9: who acts on whose body swapped.
- Lex slots: wrong object (lex A: same agent→recipient but a different object, e.g. book instead of present) and wrong person (lex B: a third person, e.g. tatínek, receives) → wrong for both v1 and v2. Never use a lex with the same object + same two persons.

## Picturability constraints
- Exactly two participants, unmistakably different: child vs adult (kluk/dědeček, holčička/maminka), man vs woman, or two different animals; never two same-class persons (two girls „kamarádka" = doc 5.13.3 → swap ambiguous; replace by holčička/babička).
- Transfer captured mid-action: object held in agent's hands, recipient's hands open/reaching, motion arrows only if the style allows; agent faces the recipient. Recipient must not already hold a similar object.
- Object big and single (dárek, míč, kniha, hrnek, jablko, květina, dopis…); not duplicated in scene.
- Verbs must be depictable as a moment: avoid „posílat" (sender and receiver apart → use „nese dopis"), „říkat/vyprávět/slibovat" (no visible object), „kupovat" (shop context, risky), „číst" (read to someone: risky — reader holds book, listener sits; acceptable with clear child-listener). „půjčovat" vs „dávat" not visually distinguishable — fine as long as the only contrast is roles.
- Animal recipients only with plausible direction (pán hází psovi míček OK; reverse "pes hází pánovi" absurd → use only if the gram distractor is still a drawable fairy-tale scene, or choose two humans).
- Picture must not show both persons giving each other (no exchange scenes).

## Diversity list (mostly ≤ 2000 most frequent words)
Verbs (≥30): dávat, podávat, nést, přinášet, házet, ukazovat, půjčovat, nabízet, kupovat, vracet, posílat (risky), psát (dopis), číst, zpívat, malovat (obrázek pro), kreslit, vařit, péct, nalévat, krájet, mazat (chleba), držet (deštník), otevírat (dveře), oblékat, obouvat, zavazovat (botu), česat, myt (ruce), utírat, foukat (na koleno), pomáhat, mávat, podepisovat (risky), sypat (zrní), házet (míč), kutálet, nosit, vozit (na vozíku), ukazovat cestu (risky), běžet/utíkat k (F10), jít/jet k, plavat k, letět k.
Objects: dárek, míč, kniha, knížka, dopis, hrnek, sklenice, jablko, hruška, banán, chléb/rohlík, dort, polévka, mléko, čaj, květina, kytice, klíč, taška, batoh, čepice, šála, bota, deštník, hračka, auto (hračka), panenka, obrázek, tužka, papír, talíř, lžíce, kolo, peníze (risky), zmrzlina, sušenka, kost (pro psa), mrkev (pro koně).
Person/animal pairs (always distinct): chlapeček–dědeček, holčička–babička, kluk–maminka, holčička–tatínek, maminka–tatínek, babička–dědeček, paní–pán, učitelka–žák, doktor–holčička, kuchař–kluk, prodavačka–pán (risky), sestra–bratr (risky: age cue needed), miminko–maminka (receiver only), pes–kočka, kočka–myš, kůň–holčička, pán–pes, holčička–kachny (plural F6), kluk–ptáci.
Prepositions/other fronts: k/ke (F10), pro + Acc (F13 pilot), word order S-first / Dat-first / Acc-Dat order (F2).

User rule (verbatim): "try to differentiate on multiple fronts for every test type. Use different objects, different verbs, different prepositions, etc. Make the tests rich in diversity while keeping the words mostly among 2000 most frequent word in the language."

## Patterns to AVOID
- Same-class persons (two girls, two boys) or kamarádka/kamarád without visible difference.
- Verbs without visible object transfer (říkat, slibovat, děkovat, věřit, pomáhat-abstract), feeling datives (líbí se mu, je mi zima), ethic dative.
- Pronoun dative without antecedent („Dává jí míč.").
- Ambiguous nominative = dative-looking forms; check every noun pair: e.g. „mamince/babičce/holčičce" OK; avoid neuter/feminine nouns whose Dat = Nom-like in speech („dítě – dítěti" fine; „kuře" risky).
- Accusative-person + dative-person sentences unless piloted (F7).

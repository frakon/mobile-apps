# 5.12 scope (Step-0 web scope explorer, 2026-10-01)

## Type
5.12 Komplexní distributivní kvantifikátory (doc2 §5.12: každý, pouze, kromě, žádný, některé). The doc's items 5.12.1 (každý), 5.12.3 (žádný) and 5.12.4 (některé) overlap with 5.10, which already covers všechny/každý vs žádný/nikdo/jen jeden/oba. **5.12 is therefore narrowed to what 5.10 does not test:**
- (a) restriction „pouze/jen + a SUBSET defined by an attribute" (doc 5.12.2 „Pouze žluté tužky jsou ořezané");
- (b) exception „všichni/všechny … kromě + Gen" (doc 5.12.5);
- (c) distributive „každý X má svůj (vlastní) Y" vs collective „X mají jeden společný Y".
The core contrast is the scope of the set: who is IN and who is OUT (restriction vs exception, or one-each vs one-shared).

Format: 4 pictures = target + gram distractor 1 (the swap partner, i.e. the swapped quantifier reading) + 2 lex distractors (wrong for BOTH sentences). Sets: two visibly different groups (by colour or kind, 2+2 or 3+1 objects/persons) whose state differs boldly (inside/outside, open/closed, with/without hat).

## Forms inventory
- Restriction „pouze/jen + attribute group" (Nom): „Pouze červená auta jsou v garáži." — depictable: yes (core majority).
- Exception „všechna … kromě + Gen": „Všechna auta kromě červeného jsou v garáži." — depictable: yes.
- Exception with persons „všichni kromě": „Všichni kluci kromě Petra mají čepici." — depictable: risky (names are not visible) → use attributes: „kromě malého kluka", „kromě kluka v brýlích".
- Exception „až na + Acc": „Všechny hrnky až na modrý jsou plné." — depictable: yes, but rarer and stylistically heavier → excluded (keep kromě only).
- „s výjimkou + Gen", „vyjma" — formal, outside 2000 words → excluded.
- Distributive „každý … svůj/vlastní": „Každé dítě má svůj balónek." — depictable: yes (3 children, 3 balloons).
- Collective „spolu/společně … jeden": „Děti drží spolu jeden velký balónek." — depictable: yes.
- Distributive „každý" in a plain universal sense („Každý kluk má čepici") — already 5.10 → excluded here.
- „Žádný", „nikdo", „jen jeden", „oba", „všechny vs žádná" — already 5.10 → excluded.
- „Některé/někteří" — logically true for "all" pictures; overlaps → excluded (brief rule).
- „Kromě" in its ADDITIVE meaning („Kromě psa má i kočku" = besides) — ambiguous with exception → FORBIDDEN; use kromě only after všichni/všechny/všechna (exceptive reading is then unique).
- „Jen" as a temporal/degree particle („jen chvilku") — not a quantifier → excluded.
- Acquisition (HYPOTHESIS; no Czech norms found online): only/except understood around 5–6+, distributive vs collective reading later (6–7); exception phrases are the hardest.

## Majority (marked) form
Restriction vs exception pair on ONE picture set (two groups A and B, 2+2 or 3+1):
- Target picture T: A-group has the state, B-group does not. Gram G: the reversed assignment (B has it, A not).
- v1 (majority) „Pouze žluté tužky jsou ořezané." → T. Swap v2 = picture G.
- v2 can be the minority exception sentence describing G: „Všechny tužky kromě žlutých jsou ořezané." (then G = the B group sharpened, A blunt). This is the swap pouze ↔ kromě: the same words „žluté", opposite set membership.
- Lex 1: all objects have the state (pouze false, kromě false). Lex 2: no object has the state (both false) — both wrong for both sentences. Note: the "all" picture is a 5.10-like foil but serves here as lex, not as target.
  If the lead wants "lex = another noun" for consistency, use another object kind with the same pattern for ONE lex slot (e.g. žluté pastelky vs tužky only if visibly different) — risky; prefer the all/none foils.

## Minority form(s)
Target 33% (66 mixed items × 1 minority variant):
1. Exception „Všechny/všichni/všechna X kromě + Gen (+ attribute) …" — about 50 items, as v2 of pouze items (above). Reason: doc 5.12.5; the most frequent spoken way of exceptions; it tests the same in/out contrast with the opposite polarity.
2. Distributive vs collective „každý … svůj" ↔ „spolu jeden" — about 16 items as whole mini-pairs: v1 „Každé dítě nese svůj kufr." (T: 3 children, 3 suitcases) / v2 „Děti nesou spolu jeden kufr." (G: 3 children carrying one big suitcase). Count: the každý-svůj variant is minority (the collective sentence is not quantifier-marked; count it as majority to keep ratio honest, or the coordinator decides). Lex: one child carries a suitcase, the others nothing (both false); children carry bags of another kind visibly (box instead of suitcase) in BOTH arrangements? — keep lex as distinct nouns: 3 children each with a box (false for kufr) — check it is false for both.

Recommendation (decision): majority = „pouze/jen + attribute group" (~67%); minority = „všechny … kromě + Gen" (~25%) + „každý … svůj" distributive (~8%). Mixed items v1 pouze / v2 kromě dominate.

## Contrast kept by minority items
- kromě v2: its target is exactly the pouze picture's gram foil (swap), so the in/out set boundary is still the tested contrast; the "all" and "none" foils are false for kromě (all: exception violated; none: "všechny" violated).
- každý-svůj: the gram foil is the collective one-shared picture → tests distributive vs collective scope.

## Pitfalls
- Existence first / visible set: both groups must be shown; with pouze, the non-selected group must be visibly present without the state, else „pouze žluté" is not testable (and a picture with only yellow pencils would be literally true). Optional lead-in „Na stole jsou žluté a modré tužky." when needed.
- Literal truth: check every wrong picture against BOTH sentences (pouze A = A yes AND B no; kromě A = A no AND all B yes).
- Agreement: kromě + Gen sg/pl matching the group: „kromě červeného (auta)", „kromě žlutých (tužek)", „kromě malého kluka"; verb agrees with the head „všechna auta … jsou", „všichni kluci … mají". Pouze/jen + Nom: „Pouze červená auta jsou…" („Jen holčička…" with a single person is 5.10 jen-jeden → avoid single-person pouze; use groups).
- Avoid additive kromě („kromě X má i Y").
- Do not use „některé", „žádný", „nikdo", „oba", „jen jeden" (5.10).
- Attribute groups must be bold at 512 px: colour, size (velký/malý), kind (kluci/holky). Max 4 objects; 3+1 for kromě singular, 2+2 for plurals.
- Do not mix pouze and jen randomly in one item; use both across items for diversity.
- Distributive items: svůj must be clearly 1:1 (3 identical objects) vs one large shared object; avoid „každý" with plain universal sense.

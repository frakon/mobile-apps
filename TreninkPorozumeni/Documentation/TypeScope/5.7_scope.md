# 5.7 scope (Vztažné věty) — TestTypeScopeRule §3

## Type
5.7 Vztažné věty (vedlejší věta přívlastková) — the child must attach the relative clause / attribute to the right figure of two interacting figures. Doc reference: test-type doc section 5.7; app items `src/items/field57.ts`.

## Forms inventory
- Subject relative, nominative „který/která/které" (pronoun = clause subject): „Opice, která má batoh, češe psa." / „Opice češe psa, který má batoh." — depictable: yes (majority)
- Object relative, accusative „kterého/kterou/které": „Medvěd, kterého lechtá víla, má mašli.", „Kotě, které fotí pirát, má batoh." — depictable: yes
- Dative relative „kterému/které": „Lev, kterému mává kočka, má korunku." — depictable: yes
- Prepositional/instrumental relative „se kterým/se kterou", „vedle kterého/které": „Ježek, vedle kterého stojí maminka, má klobouk." — depictable: yes
- „jenž" forms (jehož, jemuž) — depictable: yes, but bookish, outside child vocabulary — not used
- „co" / „kde" / „kam" relatives („Pes, co štěká…", „Dům, kde bydlí…") — depictable: risky (co is colloquial and case-less; kde/kam need places, not two figures in the existing pictures) — not used
- Temporal clauses (když…) — depictable: no (time course) — not used

## Majority (marked) form
Subject relatives with nominative „který/která/které" (the clause states the attribute „má X / drží X" or the action of the clause subject).

## Minority form(s)
Oblique relatives — the relative pronoun is not the clause subject (accusative, dative, prepositional/instrumental). Reason: with only subject relatives children could learn „the noun before který does the action". Oblique relatives force processing the pronoun case and the clause's own subject. Before P18 the type already had 66 mixed items (E = 33.0 %) but two groups had only 2.5 expected minority sentences and some minority verbs repeated (stojí 8, tančí 7, sedí 7, hraje si 6 items). P18 (2026-10-02): 8 minority sentences of the over-used verbs rewritten to subject relatives, 9 pure-majority items got an oblique-relative sentence (acc/dat) -> E = 67/200 = 33.5 %, each minority verb in ≤5 items. Order unchanged (seed 570057).

## Contrast kept by minority items
The grammatical distractor is still the picture where the attribute belongs to the other figure (same two figures, same action). Every rewrite keeps the sentence meaning, so the target/gram pictures and why-texts are unchanged; lex pictures stay wrong for both sentences.
